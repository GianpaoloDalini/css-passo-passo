Guida al CSS

Questa guida ti porta da una pagina HTML senza stile a un sito aziendale completo, con header, menu, card, tabelle, link e footer. Le pagine sono come quelle delle esercitazioni di laboratorio.

Ogni riquadro Prova è modificabile: cambi il codice a sinistra e la pagina a destra si aggiorna subito. Se sbagli, premi Ripristina.

Come usare la guida

Gli esempi usano il sito di un'azienda inventata, Seriana Logistica: magazzino, preparazione ordini e consegne. Lo costruiamo un pezzo alla volta e nel laboratorio finale lo vedi completo.

La guida ha tre parti:

  1. Parte A, ripasso HTML: la struttura della pagina, i tag che usiamo e soprattutto i link.
  2. Parte B, il CSS: regole, selettori, colori, testo, box model, link, tabelle, layout con flexbox, pagine che si adattano al telefono.
  3. Parte C, il laboratorio: il sito completo, con le regole che puoi accendere e spegnere una alla volta, e un prontuario delle proprietà.
Come lavoriamo in laboratorioNella cartella del progetto tieni index.html, il file stile.css e la cartella img con le immagini. Apri index.html nel browser e il file nell'editor. Dopo ogni modifica salva con Ctrl + S e aggiorna il browser con F5.
PARTE A

Ripasso HTML

A.1La struttura della pagina

Ogni pagina HTML ha lo stesso scheletro. Il CSS si collega nella parte head.

RigaA cosa serve
<!DOCTYPE html>Dice al browser che il file è HTML5. Va sempre nella prima riga.
<html lang="it">Contiene tutta la pagina. lang="it" dice che la lingua è l'italiano (serve ai lettori di schermo e ai motori di ricerca).
<head>Informazioni sulla pagina che non si vedono: codifica, titolo, collegamento al CSS.
<meta charset="UTF-8">Fa vedere bene le lettere accentate e il simbolo €.
<meta name="viewport" …>Sul telefono fa usare la larghezza vera dello schermo. Serve per le pagine responsive (capitolo B.13).
<title>Il testo nella scheda del browser e nei risultati di Google.
<link rel="stylesheet" href="stile.css">Collega il foglio di stile esterno.
<body>Tutto il contenuto visibile.

Prova a cancellare la riga <link …> nella scheda index.html: la pagina perde lo stile, perché il file CSS non è più collegato.

A.2Testo e contenitori

I tag dicono che cosa è ogni pezzo di contenuto. Gli attributi class e id servono per agganciare il CSS.

strong, emTesto importante (grassetto), testo enfatizzato (corsivo)in linea

Gli elementi blocco occupano tutta la larghezza e vanno a capo. Gli elementi in linea stanno nella riga di testo. Lo riprendiamo nel capitolo B.11.

Gli attributi class e id

  • class="card": un nome che puoi dare a tanti elementi. Un elemento può avere più classi separate da spazio: class="sezione chiara".
  • id="tariffe": un nome unico nella pagina. Serve anche per i link interni (capitolo A.5).

A.4Tabelle

Una tabella è fatta di righe (tr). Ogni riga contiene celle di intestazione (th) o celle normali (td).

A.5I link

Il tag a crea un collegamento. Il valore di href decide dove porta.

Il testo tra <a> e </a> è quello che si clicca. Deve far capire dove si va: «Le nostre tariffe» è meglio di «clicca qui».

I sei tipi di link

TipoEsempio di hrefCosa succede
Altra pagina del sitohref="tariffe.html"Apre un'altra pagina della stessa cartella (percorso relativo)
Sito esternohref="https://it.wikipedia.org"Apre un altro sito. Serve l'indirizzo completo con https://
Ancora (stessa pagina)href="#contatti"Salta all'elemento con id="contatti"
Torna suhref="#"Torna all'inizio della pagina
Emailhref="mailto:info@azienda.it"Apre il programma di posta. Con ?subject=… si scrive già l'oggetto
Telefonohref="tel:+390350001111"Sul telefono avvia la chiamata. Il numero si scrive senza spazi

Gli attributi utili

  • target="_blank": apre il link in una nuova scheda. Usalo per i siti esterni, così l'utente non perde la tua pagina.
  • title="…": un suggerimento che compare passando sopra con il mouse.
  • Un link può contenere un'immagine: <a href="index.html"><img src="img/logo.png" alt="Torna alla home"></a>. Si usa spesso per il logo, che riporta alla home.
Come funziona l'ancoraIl link href="#tariffe" cerca nella pagina l'elemento con id="tariffe". Il nome deve essere uguale, senza il # nell'id. È così che funziona il menu in alto nei siti delle esercitazioni.
PARTE B

Il CSS

B.1La regola CSS

HTML dice che cosa c'è nella pagina. Il CSS (Cascading Style Sheets) dice come si presenta.

Selettorea quali elementi si applica la regola: qui tutte le celle td
Proprietàche cosa cambiamo: lo spazio interno, il bordo in basso
Valorecome lo cambiamo: 10 pixel, una linea grigia di 1 pixel

Una coppia proprietà: valore; si chiama dichiarazione. Il selettore più le graffe con le dichiarazioni formano una regola.

La punteggiatura conta

  • Le dichiarazioni stanno tra parentesi graffe { }.
  • Tra proprietà e valore ci sono i due punti :. Ogni dichiarazione finisce con il punto e virgola ;.
  • Le proprietà sono in minuscolo, con il trattino: background-color.
  • Tra numero e unità non c'è spazio: 20px, non 20 px.
  • I commenti si scrivono /* così */. In HTML invece sono <!-- così -->.
Il browser non segnala gli erroriSe manca un punto e virgola o una graffa, il browser ignora la dichiarazione sbagliata, e a volte anche quelle dopo. Se uno stile «non funziona», controlla prima la punteggiatura.

Ci sono due errori: manca un ; dopo #0F3B57, quindi anche il centrato non funziona, e c'è uno spazio in 22 px. Correggili nel riquadro.

B.4Ereditarietà e cascata

Due domande: quali stili passano dai genitori ai figli? E se due regole si contraddicono, chi vince?

Ereditarietà

Le proprietà del testo (color, font-family, font-size, line-height, text-align) passano dal genitore ai figli. Per questo basta scrivere il font una volta in body.

Le proprietà della scatola (padding, margin, border, background-color, width) non si ereditano.

I link non ereditano il coloreIl browser dà ai link un suo colore (blu, viola se già visitati). Se l'header è blu scuro con testo bianco, i link restano blu: il colore va dato a loro, con header a { color: white; }.

La cascata: chi vince

  1. Vince la regola con il selettore più specifico: style="…" in linea > #id > .classe > tag.
  2. Un selettore discendente somma i pezzi: .hero h2 (classe + tag) batte h2 (solo tag).
  3. A parità di specificità vince la regola scritta più in basso nel file.

Prova a cambiare .hero h2 in h2: ora tutte e due le regole hanno lo stesso selettore e vince quella più in basso, quindi tutti i titoli diventano bianchi.

B.7Il box model

Per il CSS ogni elemento è una scatola. Dall'interno verso l'esterno: contenuto, padding, border, margin.

ProprietàCos'è
paddingLo spazio dentro la scatola, tra il contenuto e il bordo. Prende il colore di sfondo dell'elemento.
borderIl bordo. Si scrivono tre cose: spessore, stile (solid, dashed, dotted), colore. Solo un lato: border-top, border-bottom…
marginLo spazio fuori dalla scatola, che la separa dagli altri elementi. È sempre trasparente.
width / max-widthLarghezza fissa / larghezza massima. max-width si adatta agli schermi piccoli.
border-radiusAngoli arrotondati
box-shadowOmbra: spostamento orizzontale, verticale, sfocatura, colore. Es. 0 2px 6px rgba(0,0,0,0.15)

Una, due o quattro misure

box-sizing: border-boxNormalmente width è solo la larghezza del contenuto: padding e bordo si aggiungono. Con * { box-sizing: border-box; } all'inizio del CSS, width diventa la larghezza totale e i conti tornano. Prova l'interruttore nel riquadro qui sopra.

B.8I link con il CSS

Un link cambia aspetto a seconda dello stato. Le pseudoclassi selezionano proprio questi stati.

PseudoclasseQuando vale
a:linkIl link non ancora visitato
a:visitedIl link già visitato (il browser ricorda la cronologia)
a:hoverIl mouse è sopra il link
a:focusIl link è selezionato con la tastiera (tasto Tab)
a:activeIl momento del clic, mentre il tasto è premuto
L'ordine conta: LoVe HAteScrivi le regole nell'ordine Link, Visited, Hover, Active. Hanno la stessa specificità, quindi vince l'ultima (capitolo B.4). Se metti :hover prima di :visited, sui link visitati l'hover non si vede.

Tre usi tipici

  1. Link nel testo: colore dell'azienda, sottolineatura che sparisce al passaggio del mouse.
  2. Menu di navigazione: link senza sottolineatura, con padding e sfondo che cambia al passaggio. Così l'area cliccabile è più grande.
  3. Pulsante (per esempio «Chiedi un preventivo»): un link con sfondo pieno, angoli arrotondati, display: inline-block.
Non togliere il contorno del focusChi naviga con la tastiera vede dove si trova grazie al contorno del link selezionato. Se scrivi outline: none, dai sempre un altro segno visibile con :focus, come lo sfondo del menu qui sopra.

B.9Le immagini con il CSS

Con il CSS le immagini si adattano allo schermo, si centrano e si arrotondano.

  • max-width: 100%: l'immagine non esce mai dal suo contenitore, anche sul telefono.
  • height: auto: mantiene le proporzioni.
  • Un'immagine è in linea. Per centrarla: display: block + margin: 0 auto. Oppure text-align: center sul genitore.
  • border-radius arrotonda gli angoli. border-radius: 50% su un'immagine quadrata la rende un cerchio.

Restringi la finestra del browser o guarda la pagina dal telefono: l'immagine del banner si rimpicciolisce con lo schermo.

B.10Le tabelle con il CSS

Con quattro regole una tabella diventa leggibile: bordi uniti, spazio nelle celle, intestazione colorata, righe alternate.

  • border-collapse: collapse: unisce i bordi doppi delle celle in una linea sola.
  • tr:nth-child(even): seleziona le righe pari (odd = dispari). Serve per le righe a strisce.
  • tr:hover: evidenzia la riga sotto il mouse.

B.11Display e flexbox

Con display decidi come si dispone un elemento. Con display: flex metti i blocchi uno accanto all'altro: è così che si fanno le card affiancate e il menu in riga.

ValoreComportamentoEsempi
blockVa a capo e occupa tutta la larghezza. Accetta width, height e tutti i margini.div, p, h1, section
inlineSta nella riga. Ignora width, height e i margini sopra e sotto.a, span, strong, img
inline-blockSta nella riga ma accetta le misure, come un blocco.i pulsanti
noneL'elemento sparisce dalla pagina.
flexL'elemento diventa un contenitore flessibile: i suoi figli si dispongono in riga.menu, card, header

Le proprietà del contenitore flex

ProprietàA cosa serve
flex-directionrow = in riga (predefinito), column = in colonna
justify-contentDistribuisce i figli sulla linea principale: flex-start, center, space-between, space-around
align-itemsLi allinea nell'altra direzione: stretch (stessa altezza), flex-start, center
flex-wrapwrap = se non c'è posto, i figli vanno a capo
gapLo spazio tra un figlio e l'altro

Sui figli si usa spesso flex: 1: si dividono lo spazio in parti uguali.

B.12I box semantici

HTML5 ha tag che dicono che cosa è ogni zona della pagina. Funzionano come div, ma hanno un significato.

header logo, nome, menu
nav (dentro header) il menu
main il contenuto principale, uno per pagina
section id="servizi" una sezione con un titolo
section id="tariffe" un'altra sezione
footer dati dell'azienda, copyright
PrimaOraPerché è meglio
<div class="header"><header>Il lettore di schermo annuncia «intestazione»
<p><a>…</a> | <a>…</a></p><nav>Chi usa la tastiera può saltare al menu
<div id="servizi"><section id="servizi">La pagina è divisa in parti con un titolo
<div class="footer"><footer>Google capisce dove sono i dati dell'azienda

Nel CSS si selezionano con il nome del tag, senza punto: header { … }, footer { … }. Si usa anche article, per un contenuto che sta in piedi da solo, come una notizia.

B.13Pagine per il telefono

Una pagina responsive si adatta alla larghezza dello schermo. Servono tre cose.

  1. Il meta viewport nel head (capitolo A.1).
  2. Misure flessibili: max-width al posto di width, immagini con max-width: 100%, flex-wrap: wrap.
  3. Le media query: regole che valgono solo sotto una certa larghezza.

Sposta il cursore per cambiare la larghezza dello schermo simulato. Sotto i 600 pixel le card vanno in colonna e il menu va sotto il titolo.

B.14Strumenti ed errori comuni

Quando qualcosa non funziona, non tirare a indovinare: guarda che cosa vede il browser.

Gli strumenti per sviluppatori (F12)

  1. Nel browser premi F12, oppure tasto destro sull'elemento e Ispeziona.
  2. A sinistra vedi l'HTML: clicca un elemento per selezionarlo.
  3. A destra, nella scheda Stili, vedi tutte le regole che lo colpiscono. Le dichiarazioni barrate hanno perso la cascata. Quelle con un triangolo giallo hanno un errore di scrittura.
  4. Puoi cambiare i valori lì per provare. Le modifiche non si salvano: quando trovi il valore giusto, scrivilo nel tuo stile.css.
  5. Il riquadro colorato in fondo alla scheda mostra il box model dell'elemento.

Se uno stile non funziona, controlla in quest'ordine

  • Il file stile.css è collegato? Il nome in href è identico al nome del file? Il file è nella stessa cartella?
  • Hai salvato il file e aggiornato il browser? Se non cambia nulla, prova Ctrl + F5.
  • La punteggiatura: ; a fine riga, : tra proprietà e valore, graffe aperte e chiuse.
  • Il selettore: classe con il punto (.card), id con il cancelletto (#tariffe), nome uguale a quello nell'HTML.
  • La scrittura: background-color e non backgroud-color, 20px senza spazio, colori in inglese.
  • Un'altra regola più specifica vince la tua? Guardalo con F12.
  • Nell'HTML è rimasto un attributo style="…"? Batte qualsiasi regola del file CSS.
