Guida al CSS

Questa guida ripassa l'HTML che serve e spiega le basi del CSS per costruire pagine come quelle delle esercitazioni di laboratorio: fasce colorate, card, immagini, tabelle e link.

Ci sono due tipi di attività. Nei riquadri Esercizio modifichi il codice e la pagina a destra si aggiorna subito. Nei riquadri Completa scrivi le parti mancanti e premi Controlla.

Come usare la guida

Gli esempi usano il sito di un'azienda inventata, Seriana Logistica: magazzino, preparazione ordini e consegne.

  1. Parte A, ripasso HTML: la struttura della pagina, i tag che usiamo, le immagini, le tabelle e i link.
  2. Parte B, il CSS: regole, selettori, cascata, colori, testo, box model, immagini e tabelle. In fondo c'è la lista dei controlli da fare quando qualcosa non funziona.
Come lavoriamo in laboratorioNella cartella del progetto tieni index.html, il file stile.css e la cartella img con le immagini. Apri index.html nel browser e il file nell'editor. Dopo ogni modifica salva con Ctrl + S e aggiorna il browser con F5.
Nei riquadri di esercizioSe sbagli, premi Ripristina per tornare al codice iniziale. Prova sempre da solo prima di premere Mostra soluzione.
PARTE A

Ripasso HTML

A.1La struttura della pagina

Ogni pagina HTML ha lo stesso scheletro. Il CSS si collega nella parte head.

RigaA cosa serve
<!DOCTYPE html>Dice al browser che il file è HTML5. Va sempre nella prima riga.
<html lang="it">Contiene tutta la pagina. lang="it" dice che la lingua è l'italiano.
<head>Informazioni sulla pagina che non si vedono: codifica, titolo, collegamento al CSS.
<meta charset="UTF-8">Fa vedere bene le lettere accentate e il simbolo €.
<title>Il testo nella scheda del browser.
<link rel="stylesheet" href="stile.css">Collega il foglio di stile esterno.
<body>Tutto il contenuto visibile.

Apri la scheda index.html e cancella la riga <link …>: la pagina perde lo stile, perché il file CSS non è più collegato.

A.2Testo e contenitori

I tag dicono che cosa è ogni pezzo di contenuto. Gli attributi class e id servono per agganciare il CSS.

TagSignificato
h1 … h6Titoli, dal più importante al meno importante. Un solo h1 per pagina.
pParagrafo
ul / ol + liElenco puntato / numerato, con le sue voci
divContenitore: raggruppa altri elementi, per esempio una fascia della pagina o una card
strong, emTesto importante (grassetto), testo enfatizzato (corsivo)
spanContenitore dentro una riga di testo
brA capo (tag senza chiusura)

Gli attributi class e id

  • class="card": un nome che puoi dare a tanti elementi. Un elemento può avere più classi separate da spazio: class="sezione chiara".
  • id="tariffe": un nome unico nella pagina. Serve anche per i link interni (capitolo A.5).

A.3Immagini e percorsi

Il tag img non ha chiusura. Il percorso in src parte dalla cartella in cui si trova il file HTML.

AttributoA cosa serve
srcIl percorso del file immagine
altIl testo alternativo: lo leggono i lettori di schermo e compare se l'immagine non si carica. È obbligatorio.
widthLarghezza in pixel

Percorsi relativi e assoluti

PercorsoDove cerca il file
logo.pngNella stessa cartella del file HTML
img/logo.pngNella cartella img, accanto al file HTML
../img/logo.pngSale di una cartella (..) e poi entra in img
https://www.sito.it/logo.pngPercorso assoluto: un file su Internet
L'immagine non si vede?Controlla il nome del file lettera per lettera: maiuscole, estensione (.png o .jpg) e cartella. Per un server Logo.PNG e logo.png sono file diversi.

A.4Tabelle

Una tabella è fatta di righe (tr). Ogni riga contiene celle di intestazione (th) o celle normali (td).

A.5I link

Il tag a crea un collegamento. Il valore di href decide dove porta.

Il testo tra <a> e </a> è quello che si clicca. Deve far capire dove si va: «Le nostre tariffe» è meglio di «clicca qui».

I sei tipi di link

TipoEsempio di hrefCosa succede
Altra pagina del sitohref="tariffe.html"Apre un'altra pagina della stessa cartella (percorso relativo)
Sito esternohref="https://it.wikipedia.org"Apre un altro sito. Serve l'indirizzo completo con https://
Ancora (stessa pagina)href="#contatti"Salta all'elemento con id="contatti"
Torna suhref="#"Torna all'inizio della pagina
Emailhref="mailto:info@azienda.it"Apre il programma di posta. Con ?subject=… si scrive già l'oggetto
Telefonohref="tel:+390350001111"Sul telefono avvia la chiamata. Il numero si scrive senza spazi

Gli attributi utili

  • target="_blank": apre il link in una nuova scheda. Usalo per i siti esterni, così l'utente non perde la tua pagina.
  • title="…": un suggerimento che compare passando sopra con il mouse.
  • Un link può contenere un'immagine: <a href="index.html"><img src="img/logo.png" alt="Torna alla home"></a>. Si usa spesso per il logo, che riporta alla home.
Come funziona l'ancoraIl link href="#tariffe" cerca nella pagina l'elemento con id="tariffe". Il nome deve essere uguale, senza il # nell'id. È così che funziona il menu in alto nei siti delle esercitazioni.
PARTE B

Il CSS

B.1La regola CSS

HTML dice che cosa c'è nella pagina. Il CSS (Cascading Style Sheets) dice come si presenta.

Selettorea quali elementi si applica la regola: qui tutte le celle td
Proprietàche cosa cambiamo: lo spazio interno, il bordo in basso
Valorecome lo cambiamo: 10 pixel, una linea grigia di 1 pixel

Una coppia proprietà: valore; si chiama dichiarazione. Il selettore più le graffe con le dichiarazioni formano una regola.

La punteggiatura conta

  • Le dichiarazioni stanno tra parentesi graffe { }.
  • Tra proprietà e valore ci sono i due punti :. Ogni dichiarazione finisce con il punto e virgola ;.
  • Le proprietà sono in minuscolo, con il trattino: background-color.
  • Tra numero e unità non c'è spazio: 20px, non 20 px.
  • I commenti si scrivono /* così */. In HTML invece sono <!-- così -->.
Il browser non segnala gli erroriSe manca un punto e virgola o una graffa, il browser ignora la dichiarazione sbagliata, e a volte anche quelle dopo. Se uno stile «non funziona», controlla prima la punteggiatura.

B.2Dove si scrive il CSS

Ci sono tre modi. Fanno la stessa cosa, ma per un sito vero si usa il file esterno.

ModoCome si scriveQuando usarlo
In linea<h1 style="color: red;">Quasi mai: lo stile vale per un solo elemento e va ripetuto ovunque.
Interno<style> h1 { color: red; } </style> dentro headPer una pagina sola o per provare.
EsternoFile stile.css + <link rel="stylesheet" href="stile.css">Sempre, per un sito. Tutte le pagine usano lo stesso file: cambi una regola e cambia tutto il sito.

B.3I selettori

Il selettore sceglie gli elementi a cui dare lo stile. Un buon selettore colpisce tutti gli elementi giusti e solo quelli.

SelettoreEsempioColpisce
Di tagh2Tutti gli h2 della pagina
Di classe.cardTutti gli elementi con class="card"
Di id#tariffeL'unico elemento con id="tariffe"
Di gruppoh1, h2, h3Tutti gli elementi dell'elenco: una regola sola per più selettori

Prova .sezione e poi .chiara: il primo blocco ha tutte e due le classi, quindi lo colpiscono tutti e due i selettori.

B.4Ereditarietà e cascata

Due domande: quali stili passano dai genitori ai figli? E se due regole si contraddicono, chi vince?

Ereditarietà

Le proprietà del testo (color, font-family, font-size) passano dal genitore ai figli. Per questo basta scrivere il font una volta in body: lo prendono tutti gli elementi della pagina.

Le proprietà della scatola (padding, margin, border, background-color, width) non si ereditano.

I link non ereditano il coloreIl browser dà ai link un suo colore (blu, viola se già visitati). Se una fascia ha color: white, i link dentro restano blu: il colore va dato ai link con una loro classe.

La cascata: chi vince

  1. Vince la regola con il selettore più specifico: style="…" in linea > #id > .classe > tag.
  2. A parità di specificità vince la regola scritta più in basso nel file.

color colora il testo, background-color lo sfondo. I colori si scrivono con il nome o con il codice esadecimale.

B.6Il testo

Due proprietà per il testo: il tipo di carattere e la grandezza.

ProprietàEsempioEffetto
font-familyVerdana, Arial, sans-serifIl tipo di carattere. Si scrive un elenco separato da virgole: se sul computer manca il primo, il browser usa il successivo. L'ultimo è sempre una famiglia generica: serif (con le grazie), sans-serif (senza grazie) o monospace (lettere tutte larghe uguali).
font-size18pxLa grandezza del carattere in pixel. Il testo normale del browser è 16px.
I nomi con lo spazioSe il nome del carattere ha uno spazio, va tra virgolette: font-family: "Times New Roman", serif;

B.7Il box model

Per il CSS ogni elemento è una scatola. Dall'interno verso l'esterno: contenuto, padding, border, margin.

ProprietàCos'è
paddingLo spazio dentro la scatola, tra il contenuto e il bordo. Prende il colore di sfondo dell'elemento.
borderIl bordo. Si scrivono tre cose: spessore, stile (solid continuo, dashed a trattini, dotted a puntini), colore. Per un solo lato: border-top, border-right, border-bottom, border-left.
marginLo spazio fuori dalla scatola, che la separa dagli altri elementi. È sempre trasparente.
width / max-widthLarghezza fissa / larghezza massima. Con max-width la scatola si stringe sugli schermi piccoli.
border-radiusAngoli arrotondati

Una, due o quattro misure

box-sizing: border-boxNormalmente width è solo la larghezza del contenuto: padding e bordo si aggiungono. Con * { box-sizing: border-box; } all'inizio del CSS, width diventa la larghezza totale e i conti tornano. Prova l'interruttore nel riquadro qui sopra.

B.8Le immagini con il CSS

Con il CSS le immagini si adattano allo schermo, si centrano e si arrotondano.

  • max-width: 100%: l'immagine non esce mai dal suo contenitore, anche sul telefono.
  • Per centrare un'immagine: display: block (la trasforma in un blocco) + margin: 0 auto.
  • border-radius arrotonda gli angoli. border-radius: 50% su un'immagine quadrata la rende un cerchio.

B.9Le tabelle con il CSS

Con poche regole una tabella diventa leggibile: bordi uniti, spazio nelle celle, intestazione colorata, righe alternate.

  • border-collapse: collapse: unisce i bordi doppi delle celle in una linea sola.
  • Una regola per th e una per td valgono per tutte le celle: non serve uno style per ogni cella.
  • tr:nth-child(even): seleziona le righe pari (odd = dispari). Serve per le righe a strisce.

B.10Se qualcosa non funziona

Non tirare a indovinare: controlla in quest'ordine.

  • Il file stile.css è collegato? Il nome in href è identico al nome del file? Il file è nella stessa cartella?
  • Hai salvato il file e aggiornato il browser? Se non cambia nulla, prova Ctrl + F5.
  • La punteggiatura: ; a fine riga, : tra proprietà e valore, graffe aperte e chiuse.
  • Il selettore: classe con il punto (.card), id con il cancelletto (#tariffe), nome uguale a quello nell'HTML.
  • La scrittura: background-color e non backgroud-color, 20px senza spazio, colori in inglese, esadecimale con il #.
  • Un'altra regola più specifica vince la tua (capitolo B.4)?
  • Nell'HTML è rimasto un attributo style="…"? Batte qualsiasi regola del file CSS.
